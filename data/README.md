# Data and benchmark specifications

This project is theory-first and does **not** depend on a pretrained model or a scraped observational dataset.

`benchmark_v1.jsonl` is a deterministic **synthetic benchmark specification** generated by `scripts/generate_benchmark.py`. Each row records a graph family, problem size, coupled old/new correlation, testing margin, error level, and random seed. The graph and stochastic execution distributions are then generated from the specification.

Why specifications rather than giant committed arrays?

- exact reproducibility from small immutable seeds;
- no accidental dataset leakage or licensing ambiguity;
- easy scaling to millions of trials on local GPUs;
- theory-aligned parameter sweeps;
- simpler artifact review.

Large result files belong in `results/` and are intentionally git-ignored. Archive final paper artifacts separately with checksums when experiments are frozen.
