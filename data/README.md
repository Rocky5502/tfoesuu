# Data and benchmark specifications

This project is theory-first and does **not** depend on a pretrained model or a scraped observational dataset.

The checked-in files are deterministic synthetic **specification datasets**:

- `benchmark_v1.jsonl` — Gaussian graph-allocation stress grid generated by `scripts/generate_benchmark.py`.
- `replay_benchmark_v1.jsonl` — Bernoulli paired-vs-independent replay grid generated by `scripts/generate_replay_benchmark.py`.
- `software_subject_benchmark_v1.jsonl` — executable randomized-resource-allocator configurations generated by `scripts/generate_subject_benchmark.py`.
- `counterfactual_replay_benchmark_v1.jsonl` — P15 four-way replay stress specifications generated by `scripts/generate_counterfactual_benchmark.py`.
- `threshold_replay_phase_v1.jsonl` — 24 P18 thresholded-replay specifications spanning zero, matched-scale, and fixed positive fairness tolerances, generated by `scripts/generate_threshold_replay_phase.py`. These are parameters for exact theorem/code audits, not measured outcomes.
- `control_replay_structural_cases_v1.jsonl` — six exact P19 matched-control fixtures generated by `scripts/generate_control_replay_structural_cases.py`, covering feasible/infeasible control topology and exact weighted fractional-cover values.
- `partial_replay_benchmark_v1.jsonl` — P17 partial-synchronized-replay 168-row parameter stress grid generated by `scripts/generate_partial_replay_benchmark.py`; every row is executable via `experiments/validate_partial_replay_manifest.py`, which materializes all legal groups up to the row's size cap and checks the theorem code without producing empirical findings.
- `partial_replay_structural_cases_v1.jsonl` — eight exact P17 theorem fixtures generated by `scripts/generate_partial_replay_structural_cases.py`: coherent equality, six K_n pair-group finite-gap cases, and one finite-information/infeasible-edge-witness case. Each row records the exact normalized raw-contrast cost expected under the frozen homogeneous single-changed-endpoint family; this value equals C_vert and is checked against the executable scheduler.
- `partial_replay_scope_cases_v1.jsonl` — deterministic scope-falsification data generated by `scripts/generate_partial_replay_scope_cases.py`. Its first frozen case is a heterogeneous fairness-preserving null for which the homogeneous raw-contrast predicate fires at a recorded shared tape value. The full executable tape partition gives rejection set `(0.20,0.30] U (0.40,0.45]` with exact uniform-tape measure `0.15`. This is an analytic counterexample to naive theorem generalization, not an empirical false-positive rate.
- `fairlearn_public_v2_results_v1.json` — provenance-bound aggregate of the
  complete fourteen-record historical Fairlearn parent/repair census.
- `fairlearn_public_v2_row_audit_v1.json` — exact affected-row counts,
  fractions, and protected-tuple strata derived from the immutable external
  transcripts and input bundle. It contains aggregates only, not raw public
  dataset rows.

Each row records the parameters and immutable seed needed to regenerate the corresponding stochastic experiment. The generated outcome samples themselves are not committed.

Why specifications rather than giant committed arrays?

- exact ground truth and reproducibility;
- no accidental leakage or licensing ambiguity;
- easy scaling to millions of trials on local GPUs;
- theory-aligned parameter sweeps;
- compact artifact review;
- clean separation between frozen inputs and generated results.

Large result files belong in `results/` and are intentionally git-ignored. When publication experiments are frozen, archive the exact benchmark manifests, source commit, environment metadata, commands, and result checksums together.


## Public evaluation datasets

`public_benchmark_registry_v1.jsonl` is a separate seven-entry registry for a separate planned theorem-aligned public-data evaluation: Adult, Bank Marketing, German Credit, COMPAS, Law School GPA, MEPS Panel 21, and Default Credit.  It stores source metadata only; raw third-party datasets are not vendored into this repository.  The completed historical Fairlearn parent/repair census is distinct from this planned experiment; see the aggregate files above. Publication experiments must download each dataset from its recorded authoritative source, freeze preprocessing/split seeds, and record a local content hash before results are admitted to the paper.
