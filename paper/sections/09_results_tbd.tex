\paragraph{Planned statistical reporting.}
For each dataset and replay regime, the final table states the exact number of
independent trials, point estimates for type-I/type-II error, and a binomial
confidence interval in the accompanying result artifact. Query/execution counts
are deterministic whenever they are fixed by a theorem-backed schedule;
otherwise the aggregation rule must be declared by the renderer. The primary
comparison is execution cost at a common confidence target, not classifier
accuracy.

\paragraph{Replacement gate.}
The \textsc{TBD} table and figure may be replaced only when
(i) all seven dataset adapters succeed from a clean frozen commit;
(ii) every result row names a frozen dataset ID, source hash, and seed;
(iii) the complete matrix passes \texttt{PublicResultRow} validation;
(iv) the plotting and table scripts consume only immutable result JSONL;
(v) all rows share one source commit and one registered protocol; and
(vi) the resulting PDF passes manuscript consistency, bibliography, and visual
QA gates. No hand-entered publication value is permitted.
