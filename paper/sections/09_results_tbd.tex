\paragraph{Planned statistical reporting.}
For each dataset and replay regime, the final table will state the exact number
of independent trials, point estimates for type-I/type-II error, and a
binomial confidence interval. Query/execution counts are deterministic whenever
they are fixed by the theorem schedule; otherwise we report the appropriate
mean/median together with an interval or quantile summary. The primary
comparison is execution cost at a common confidence target, not classifier
accuracy.

\paragraph{Replacement gate.}
The \textsc{TBD} table and figure may be replaced only when
(i) all seven dataset adapters succeed from a clean environment;
(ii) every result row names a frozen benchmark ID and seed;
(iii) the result schema passes validation;
(iv) the plotting/table scripts consume only immutable result JSONL; and
(v) the resulting PDF passes the manuscript consistency, bibliography, and
visual QA gates.
